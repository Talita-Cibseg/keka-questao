🚀 KEKA QUESTÃO
> **"Conhecimento se conquista. Cada questão é um desafio."**
O KEKA QUESTÃO é uma aplicação web gamificada desenvolvida para treinar fundamentos da Língua Portuguesa de forma interativa, com sistema de níveis, cronômetro por desafio, métricas de desempenho e acompanhamento visual de evolução.
---
✨ Funcionalidades
🎯 Níveis de Dificuldade: Quatro modos de jogo (Fácil, Intermediário, Difícil e Extremo) com metas de tempo decrescentes e multiplicadores de XP.
📚 Filtro por Assuntos: Banco de questões categorizado em Acentuação, Ortografia, Classes de Palavras, Sintaxe, Concordância, Regência/Crase e Pontuação.
⏱️ Cronômetro Dinâmico: Barra de contagem regressiva em tempo real para simular a pressão de provas e concursos.
📊 Painel de Desempenho & Gráficos: Visualização interativa da taxa de evolução por missão e comparativo de acertos/erros por assunto utilizando Chart.js, além de diagnóstico automático dos tópicos que precisam de revisão.
🏆 Gamificação & Ranking Pessoal: Sistema de XP acumulado, moedas, sequência de acertos (streak), patentes de nível e medalhas desbloqueáveis.
📜 Histórico Persistente: Armazenamento automático do progresso, estatísticas e histórico das últimas questões respondidas diretamente no navegador via `localStorage`.
---
🛠️ Tecnologias Utilizadas
HTML5 Semântico: Estruturação acessível e responsiva (Mobile-First).
CSS3 Moderno: Estilização com variáveis CSS (`:root`), Flexbox, CSS Grid e identidade visual em azul-petróleo e roxo.
JavaScript (ES6+): Lógica de estado, manipulação do DOM, controle de temporizadores (`setInterval`), filtragem dinâmica e persistência de dados (`localStorage`).
Chart.js: Renderização de gráficos de linha e barras para análise de desempenho.
